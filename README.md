## Setting Up and Installation

- You need to have Node.js first

- Go to backend directory and run this in the terminal

```bash
npm install
npm install mysql2
```

- Open MySQL and create Database

- Check connection.js file in backend/db and replace host, user, password and database accordingly to your schema in mysql

## Starting Up

- in backend directory, run this in the terminal

```bash
node server.js
```

- You will see something like "Server running at http://localhost:3000"

- You are now good to go and open index.html with live server
